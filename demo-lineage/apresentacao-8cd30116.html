Por que dá para confiar nisso

Dois caminhos independentes chegam ao mesmo número. O pipeline de métricas e o de traces não se falam: um agrega contadores, o outro registra spans. Somados em separado:
métrica token.usage 3,450,821
soma dos atributos dos spans 3,450,821
Idênticos. É isso que sustenta construir dashboard em cima deste dado.

Quem autorizou o quê

user_temporary36accept
config19accept
user_permanent2accept
config = já estava na allowlist · user_temporary = você aprovou na hora · user_permanent = você aprovou para sempre. A procedência de cada decisão é registrada, não inferida.

O que esta sessão não responde

Dito na cara, porque a alternativa é alguém descobrir depois:
  • Não há atribuição a skill, plugin ou MCP — nenhum código de terceiros rodou aqui. O atributo existe; o dado desta sessão não o exercita.
  • Nenhuma permissão foi negada — 57 de 57 aceitas. Não dá para afirmar nada sobre allowlist barrando.
  • Uma sessão não é amostra. Uma pessoa, uma tarefa, um dia. Serve para mostrar o mecanismo, não para concluir sobre a empresa.
  • O lineage para na fronteira da chamada. Sabemos que o modelo foi chamado e o que voltou; o que acontece do lado dele não é observável daqui.

O que dá para perguntar com este dado

A ponte entre uma sessão e um dashboard de verdade.

  • Quanto custa cada pessoa, time ou organização — identidade viaja nos três sinais, sem join.
  • Quanto do orçamento vai para subagente — aqui foram 5,8%, e ninguém enxerga isso lendo o chat.
  • Quanto tempo a IA passa esperando gente — e se a allowlist está trabalhando ou virou carimbo.
  • Se uma versão nova quebrou a correlação — a cobertura de TraceId muda entre versões, em silêncio.
  • Se algo se perdeu no caminho — event.sequence detecta buraco por execução.
Tudo isso já está no dado coletado. O que falta é o painel, não a instrumentação.

Como reproduzir

  1. Preparar o ambiente num terminal:
    eval "$(bash scripts/capture_session.sh env)"
  2. Confirmar que pegou:
    bash scripts/capture_session.sh check
  3. Abrir o Claude Code nesse mesmo terminal e trabalhar normalmente:
    claude
  4. Ao terminar, /exit, e gerar tudo:
    python3 scripts/render_session_html.py <session> --apresentacao
    python3 scripts/render_session_html.py <session> --dump demo-lineage/
Cada número desta página é conferível. O dump em dados/*.jsonl traz todos os atributos de logs, spans e métricas — dá para refazer as contas sem acesso ao banco. Identidade vai mascarada, não removida: as chaves continuam lá com valor de placeholder, porque o fato de identidade viajar nos três sinais é parte do achado.
